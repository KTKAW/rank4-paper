S1.1 The original scalar budget at an actual prefix
A cyclic order is proper at v when every directed two-step path u → v → w occurs clockwise as
u,v,w. A wiggle exchanges cyclically adjacent vertices with zero connecting entry. A proper
wiggle class allows a different representative, within that same class, for the properness of each
vertex. It does not require one representative proper at all vertices simultaneously. A proper
mutation moves the mutated vertex past its outgoing block, preserving the relative order of the
other vertices; nonneighbors can lie on either side of the cut. A class is totally proper if every
finite descendant under these proper mutations is proper.
